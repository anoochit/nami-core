# Security Policy

## Supported Versions

We take the security of Nami very seriously. The following versions of Nami are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| v0.9.x  | :white_check_mark: |
| < v0.9  | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in Nami, please do **NOT** report it publicly through the public issue tracker or pull requests. Instead, follow the process below to ensure the vulnerability is handled securely and responsibly:

1. **Email the Security Team:** Send a detailed report to [INSERT SECURITY EMAIL, e.g., security@nami.ai] containing:
   - A description of the vulnerability.
   - The potential impact (e.g., privilege escalation, arbitrary code execution).
   - Detailed, step-by-step instructions (or a proof-of-concept script) to reproduce the issue.
2. **Acknowledgment:** A member of our team will acknowledge receipt of your report within **48 hours** and provide a tracking ID.
3. **Investigation & Fix:** We will investigate the issue and, if validated, work on a patch or mitigation strategy. We will keep you updated on our progress throughout this process.
4. **Public Disclosure:** Once a fix is released and verified, we will publicly disclose the vulnerability (crediting you for the discovery, if you wish).

We request that you keep all details of the vulnerability confidential until we have had a reasonable amount of time to address and patch the issue. Thank you for helping keep Nami safe and secure!
