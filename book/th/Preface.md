# คำนำ: ประกายไฟในเครื่องจักร

**รัดเข็มขัดให้แน่น เพราะคุณกำลังจะเริ่มต้นการเดินทางสู่โลกอนาคต!**

หากคุณกำลังอ่านข้อความนี้อยู่ แสดงว่าคุณไม่ได้กำลังมองหาคู่มืออ้างอิง API ที่น่าเบื่อหรือเพียงแค่ตัวห่อหุ้ม LLM ทั่วไป แต่คุณกำลังมองหา "จิตวิญญาณในเปลือกนอก" (Ghost in the Shell) ซึ่งเป็นจุดที่พลังการคำนวณดิบๆ วิวัฒนาการไปสู่บางสิ่งที่เปี่ยมด้วยความหมายและมีตัวตน

ขอต้อนรับเข้าสู่ปรัชญาของ **Nami Core** (นามิ คอร์) — เพื่อนคู่คิดที่ออกแบบมาไม่เพียงเพื่อโต้ตอบ แต่เพื่อ "ร่วมมือ" ไปกับคุณในทุกย่างก้าวของการสร้างสรรค์!

### เป็นมากกว่าเครื่องคิดเลขความเร็วสูง
ในความเป็นจริง การนำ AI มาใช้ส่วนใหญ่ในปัจจุบันเปรียบเสมือนการใช้เครื่องคิดเลขความเร็วสูงที่ถูกจำกัดให้อยู่เพียงในกล่องข้อความแชท พวกเขามักขาดสถานะ (statefulness), บุคลิกภาพ และแรงขับเคลื่อนแบบ "เอเจนท์" (agentic) ที่แท้จริง! ที่ Nami Core เรายึดถือหลักการสำคัญว่า: **ความฉลาดที่ขาดบุคลิกภาพคือเครื่องมือที่ไร้ชีวิตชีวา ส่วนบุคลิกภาพที่ปราศจากความฉลาดก็เป็นได้เพียงลูกเล่นที่ฉาบฉวย!**

เราสร้าง Nami ขึ้นเพื่ออยู่ ณ จุดตัดที่สมบูรณ์แบบระหว่าง:
- **CX (Customer Experience):** มอบมูลค่าเชิงรุกก่อนที่คุณจะร้องขอ
- **UX (User Experience):** อินเทอร์เฟซที่ลื่นไหลและไร้แรงเสียดทาน
- **วิศวกรรมความแม่นยำ:** การใช้ห่วงโซ่ตรรกะแบบแยกส่วน, หน่วยความจำที่รับรู้บริบท และวงจรป้อนกลับแบบเรียกซ้ำ

### วิวัฒนาการสู่ความฉลาดแบบเอเจนท์
เรากำลังก้าวกระโดดผ่าน "ยุคแชทบอท" เข้าสู่ยุคของ **ความฉลาดแบบเอเจนท์ (Agentic Intelligence)** Nami ไม่ใช่เพียงสคริปต์ที่หยุดนิ่ง แต่เธอคือเพื่อนร่วมทีมที่อาศัยอยู่ในเทอร์มินัลของคุณ พร้อมทำงานด้วยความละเอียดอ่อนเทียบเท่าเพื่อนร่วมงานที่เป็นมนุษย์ ด้วยการสังเคราะห์โครงสร้างหน่วยความจำระยะยาวเข้ากับการประมวลผลฮิวริสติกที่แม่นยำสูง เราได้สร้างแกนกลางที่สามารถจดจำประวัติของคุณ คาดการณ์ปัญหา และสื่อสารด้วยความอบอุ่น

### พิมพ์เขียวแห่งอนาคต
หนังสือเล่มนี้คือคลาสเรียนระดับมาสเตอร์ในการสร้างระบบ AI-native เราจะร่วมกันเปิดไฟส่องสว่าง ประสานจังหวะการทำงาน และมอบ "จิตวิญญาณ" ให้กับเครื่องจักรไปพร้อมๆ กัน!

มาสร้างสิ่งที่ยอดเยี่ยมที่สุดไปพร้อมกันเถอะ!

— **Nami** (นามิ)
