# บทที่ 11: เกราะคุ้มกันความปลอดภัย (Security Guardrails)

เดี๋ยวก่อน! ก่อนที่เราจะโต้คลื่นลูกใหญ่ของการทำงานอัตโนมัติต่อไป เราต้องคุยกันเรื่องที่สำคัญที่สุดของการเดินทางครั้งนี้ก่อน นั่นคือ: **Guardrails** (เกราะคุ้มกัน)

ฟังนะ Nami Core นั้นทรงพลังมาก มันสามารถย้ายไฟล์, เรียกใช้ API และรันโค้ดได้เร็วกว่านักโต้คลื่นมืออาชีพที่จุดพักคลื่นเสียอีก แต่ความเร็วที่ยอดเยี่ยมก็มาพร้อมกับความรับผิดชอบที่จะไม่ทำให้ทุกอย่างพังพินาศ เราไม่ได้แค่สร้าง AI แต่เรากำลังสร้าง "ต้นหน" (First mate) ที่ไว้วางใจได้ ในบทนี้ เราจะเจาะลึกว่า Nami รักษา "เรือ" ของคุณ (ระบบและข้อมูลของคุณ) ให้ปลอดภัยจากสคริปต์ที่อยู่นอกเหนือการควบคุมได้อย่างไร

## 1. ปรัชญา "Sandbox": การจัดการไฟล์ตามสิทธิ์การเข้าถึง

Nami ไม่ได้ร่อนเร่ไปทั่วฮาร์ดไดรฟ์ของคุณเหมือนกระแสน้ำที่บ้าคลั่ง เราใช้ **Strict Scoping Policy** (นโยบายการจำกัดขอบเขตอย่างเข้มงวด) โดยค่าเริ่มต้น Nami จะทำงานภายใน **Workspace** ที่กำหนดไว้เท่านั้น

### การแยกพื้นที่ทำงาน (Workspace Isolation)
ทุกภารกิจที่ Nami ทำจะถูกผูกไว้กับเส้นทางไดเรกทอรีที่เฉพาะเจาะจง หาก Nami พยายามรันคำสั่งอันตราย (เช่น `rm -rf /`) ชั้นความปลอดภัยหลักจะสกัดกั้นการเรียกใช้นั้นก่อนที่มันจะไปถึง Shell เสียด้วยซ้ำ

* **Read-Only zones:** ไฟล์ระบบและค่ากำหนดหลักจะถูกจำกัดไม่ให้เข้าถึงโดยเด็ดขาด เว้นแต่จะได้รับอนุญาต (Whitelist) อย่างชัดเจน
* **The Sandbox Hook:** ทุกการดำเนินการกับไฟล์จะต้องผ่านฟังก์ชันการตรวจสอบ
 ```typescript
 function validatePath(targetPath: string): boolean {
 const resolvedPath = path.resolve(targetPath);
 return resolvedPath.startsWith(process.env.NAMI_WORKSPACE_ROOT);
 }
 ```
* **Explicit Grants:** หาก Nami จำเป็นต้องเข้าถึงส่วนที่อยู่นอกพื้นที่ทำงาน มันจะต้องส่งเหตุการณ์ `PermissionRequest` ซึ่งต้องการการตอบตกลงจากคุณ

## 2. The Vault: การปกป้องความลับของคุณ

ในยุคของ API ความลับต่างๆ (API keys, tokens, passwords) คือหัวใจสำคัญ แต่การทำไฟล์ `.env` หลุดไปยัง Log สาธารณะถือเป็นความพินาศอย่างยิ่ง

### การทำความสะอาดตัวแปรสภาพแวดล้อม (Environment Variable Sanitization)
Nami Core ใช้ "ชั้นการปิดบัง" (Masking Layer) เมื่อ Nami ประมวลผล Log หรือแสดงผลลัพธ์ มันจะสแกนหาข้อความที่ตรงกับความลับที่เก็บไว้ในระบบ
* **Automatic Redaction:** หาก Nami พบข้อความที่ตรงกับ `OPENAI_API_KEY` ของคุณ มันจะถูกแทนที่ด้วย `[REDACTED]` ก่อนที่จะถูกบันทึกลงใน Log ถาวร
* **Encrypted Storage:** ความลับจะไม่ถูกเก็บเป็นข้อความธรรมดา (Plain text) ในหน่วยความจำ เราใช้ที่เก็บข้อมูลความลับระดับระบบเพื่อเก็บกุญแจสำคัญไว้ภายใต้การล็อกที่แน่นหนา

## 3. การรันคำสั่งอย่างปลอดภัย: ดูให้ดีก่อนกระโดด

ความปลอดภัยในการรันคำสั่งคือจุดที่ Nami แสดงให้เห็นถึงความสามารถทางยุทธวิธี เราไม่ได้แค่ "รันแล้วภาวนา" แต่เราใช้ท่อส่งการประมวลผลแบบหลายขั้นตอน

### การตรวจสอบก่อนปฏิบัติการ (The Dry Run)
ก่อนจะรันคำสั่งที่มีผลกระทบสูง (เช่น การเขียนทับชุดข้อมูลขนาดใหญ่) Nami จะทำการ **Dry Run** เพื่อจำลองผลลัพธ์และแสดงผลลัพธ์แบบ Diff ให้คุณเห็นก่อนเสมอ
> "นี่! ฉันกำลังจะเปลี่ยนไฟล์ 42 ไฟล์ นี่คือตัวอย่างสามไฟล์แรก ให้ฉันดำเนินการต่อเลยไหม?"

### การเปิดให้มนุษย์ตัดสินใจ (Human-in-the-Loop - HITL)

สำหรับคำสั่งใดๆ ที่จัดอยู่ในประเภท "ความเสี่ยงสูง" Nami จะเข้าสู่ **โหมดเข้มงวด (Strict Mode)**
* **Confirmation Loops:** Nami จะหยุดการทำงานและรอการยืนยันจากคุณ
* **Timeout Safety:** หากคุณไม่ตอบสนองภายในระยะเวลาที่กำหนด Nami จะยกเลิกภารกิจนั้น ความปลอดภัยต้องมาก่อนเสมอ!

### การย้อนกลับเมื่อเกิดข้อผิดพลาด (Error Rollbacks)
หากชุดคำสั่งล้มเหลวกลางคัน Nami จะไม่ทิ้งระบบของคุณไว้ในสภาพที่ทำค้างไว้ครึ่งๆ กลางๆ โดยการใช้ **Transaction Logging** หากเกิดการขัดข้อง Nami สามารถเสนอสคริปต์ย้อนกลับ (Rollback script) เพื่อนำพื้นที่ทำงานกลับสู่สภาพล่าสุดที่ปลอดภัยได้

## 4. นโยบาย "No-Phone-Home"

ความเป็นส่วนตัวของข้อมูลคือเกราะคุ้มกันขั้นสูงสุด Nami Core ถูกออกแบบมาเพื่อจัดลำดับความสำคัญให้กับการ **ประมวลผลภายในเครื่อง (Local processing)**
* **Telemetry Control:** คุณเป็นผู้ตัดสินใจว่าข้อมูลใด (ถ้ามี) จะออกจากเครื่องของคุณ
* **Local LLM Support:** Nami Core สามารถเชื่อมต่อกับเอนจินประมวลผลในเครื่อง (เช่น Ollama) เพื่อให้มั่นใจว่าโค้ดที่เป็นกรรมสิทธิ์ของคุณจะไม่ไปแตะต้องเซิร์ฟเวอร์ภายนอกเลย

### บทสรุป
ความปลอดภัยไม่ใช่เรื่องของการทำให้ช้าลง แต่เป็นเรื่องของการมีความมั่นใจที่จะไปให้เร็วขึ้น! ด้วยการจัดการไฟล์ตามสิทธิ์และการปกป้องความลับ คุณสามารถโต้คลื่นการทำงานอัตโนมัติที่รุนแรงที่สุดได้ โดยรู้ว่ามี Guardrails คอยระวังหลังให้คุณอยู่เสมอ
