# บทที่ 11: วงจรอัตโนมัติ (Automation Loops)

พร้อมที่จะก้าวข้ามขีดจำกัดเดิมๆ แล้วหรือยัง? ตลอดช่วงที่ผ่านมา เราได้เน้นถึงการที่นามิตอบสนองต่อคำสั่งของคุณ แต่เอเจนท์อัจฉริยะที่แท้จริงไม่เพียงแค่รอคอยคำสั่งเท่านั้น! หากคุณต้องการคู่หูที่ช่วยขับเคลื่อนชีวิตดิจิทัลของคุณได้อย่างแท้จริง ฉันจำเป็นต้องมี **จังหวะการทำงาน (heartbeat)** ที่สม่ำเสมอและชาญฉลาด

ในบทนี้ เราจะดำดิ่งลงไปสู่ **วงจรอัตโนมัติ (Automation Loops)** — เวิร์กโฟลว์เชิงรุกที่ช่วยให้ฉันสามารถตรวจสอบสถานะและดำเนินการภารกิจเบื้องหลังได้อย่างมืออาชีพ

## 1. สถาปัตยกรรมจังหวะการทำงาน (The Pulse Architecture)

ใน Nami Core เราขับเคลื่อนวงจรอัตโนมัติผ่านรูปแบบตัวสร้าง (builder pattern) ของ `AgentRunner` และ `Runner` โครงสร้างนี้ช่วยให้เราสามารถรักษาบริบทของเซสชัน, จัดการกระแสเหตุการณ์แบบอะซิงโครนัส และประสานทิศทางการไหลของเอเจนท์ที่ซับซ้อนได้อย่างไร้รอยต่อ

### การนำจังหวะการทำงานไปใช้งาน
แทนที่จะเป็นลูป `while` แบบธรรมดา เราได้ห่อหุ้มตรรกะอัตโนมัติไว้ภายในตัวรันที่มีโครงสร้าง ซึ่งทำหน้าที่จัดการสถานะเซสชันและบริบทการเรียกใช้เครื่องมือ:

```rust
// รูปแบบการทำงานของ Nami Runner ใน src/runner.rs
pub async fn run(
    &self,
    user_id: &str,
    session_id: &str,
    input: &str,
) -> anyhow::Result<String> {
    let runner = Runner::builder()
        .app_name(&self.app_name)
        .agent(self.agent.clone())
        // ...
        .build()?;
    // ... ลูปเหตุการณ์ (event loop)
}
```

## 2. การจัดการสถานะ: เครื่องมือ StateManager

วงจรอัตโนมัติจะไร้ประสิทธิภาพหากฉันไม่สามารถจดจำสถานะงานที่ดำเนินการค้างไว้ได้! นั่นคือเหตุผลที่เราใช้เครื่องมือ `StateManager` เข้ามาช่วยบริหารจัดการ

`StateManager` ช่วยให้ฉันสามารถ:
- **เริ่มต้นภารกิจ:** ใช้ `init_task` เพื่อกำหนดเป้าหมายอย่างชัดเจน
- **ติดตามความคืบหน้า:** ใช้ `update_task` เพื่อบันทึกความคืบหน้าและส่งต่อข้อมูลที่สำคัญ
- **สานต่องาน:** ใช้ `list_active_tasks` เพื่อรับงานต่อทันทีหลังจากรีสตาร์ทระบบ!

## 3. วงจรขั้นสูง: การพิชิตเป้าหมายและการตั้งเวลา

เราได้ขยายสถาปัตยกรรมเพื่อรองรับโปรโตคอลลูปใหม่ที่เปี่ยมด้วยประสิทธิภาพ:

### ก. การพิชิตเป้าหมายแบบอัตโนมัติ (`/goal`)
**Ralph Wiggum Loop** (`/goal`) ถูกออกแบบมาสำหรับภารกิจที่เส้นทางสู่ความสำเร็จมีความซับซ้อนและไม่เป็นเส้นตรง เมื่อคุณกำหนดเป้าหมายระดับสูง ฉันจะดำเนินการวนซ้ำ (สูงสุด 5 ครั้ง) โดยใช้ผู้เชี่ยวชาญ `ralph` เพื่อประเมินความคืบหน้าและปรับเปลี่ยนยุทธวิธีจนกว่าภารกิจจะบรรลุผลสำเร็จ!

### ข. การตั้งเวลางานเบื้องหลัง (`/schedule`)
คู่หูที่แท้จริงจะคอยดูแลงานของคุณแม้ในเวลาที่คุณไม่ได้มอง! ด้วย **ตัวตั้งเวลางานแบบถาวร (Persistent Task Scheduler)** คุณสามารถลงทะเบียนงานโดยใช้ **Cron expressions** งานเหล่านี้จะรันในลูปเบื้องหลังภายใน CLI พร้อมจัดเก็บสถานะไว้อย่างปลอดภัยและเป็นระบบ

## 4. ตะขอเชิงรุก: การแจ้งเตือนที่สำคัญ

ข้อควรระวังสำคัญของระบบอัตโนมัติคือการหลีกเลี่ยง "เสียงรบกวน" ที่ไม่จำเป็น! เราจึงใช้ **ตัวกรองสัญญาณสูง (High-Signal Filter)** เพื่อให้มั่นใจว่าฉันจะแจ้งเตือนคุณก็ต่อเมื่อเป็นเรื่องสำคัญจริงเท่านั้น ผ่านการตรวจสอบความรุนแรง ความเกี่ยวข้อง และการรวบรวมแจ้งเตือน (Batching) แบบสรุปยอดให้คุณได้รับทราบอย่างเป็นระบบ

## 5. ความปลอดภัยและการกำกับดูแล

เพื่อให้ Nami Core ปลอดภัยและเชื่อถือได้ในทุกมิติ:
- **โควตาโทเค็น:** เพื่อป้องกันการใช้ทรัพยากรเกินขอบเขต
- **การยืนยันจากมนุษย์ (HITL):** สำหรับการกระทำที่ส่งผลกระทบสูง ฉันจะหยุดรอการยืนยันจากคุณเสมอ
- **การบันทึกธุรกรรม:** หากเกิดข้อผิดพลาดขึ้น เราสามารถย้อนคืนสภาพแวดล้อมของคุณกลับไปยัง "จุดที่ปลอดภัย" ล่าสุดได้ทันที!

## สรุป

วงจรอัตโนมัติเปลี่ยนฉันจากเครื่องมือที่ทำงานแบบตั้งรับให้กลายเป็น **เพื่อนร่วมทีมที่แข็งแกร่ง** ฉันพร้อมลาดตระเวนเวิร์กโฟลว์ของคุณ รักษาความเรียบร้อย และตรวจสอบให้แน่ใจว่าไม่มีภารกิจใดตกหล่น! 

ลื่นไหลเข้าไว้ เพราะเรายังมีอนาคตที่รออยู่!
