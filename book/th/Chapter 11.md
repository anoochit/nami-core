# บทที่ 11: วงจรอัตโนมัติ (Automation Loops)

พร้อมที่จะถอดล้อพยุงออกหรือยัง? ที่ผ่านมาเราคุยกันเรื่องที่นามิตอบสนองต่อคำสั่งของคุณ แต่เอเจนท์สารพัดประโยชน์ที่แท้จริงไม่ได้แค่รอพรอมต์เท่านั้น! เพื่อจะเป็นคู่หูที่แท้จริงในชีวิตดิจิทัลของคุณ ฉันต้องการ **จังหวะการเต้นของหัวใจ (heartbeat)** ที่สม่ำเสมอ!

ในบทนี้ เราจะดำดิ่งลงไปใน **วงจรอัตโนมัติ (Automation Loops)** — เวิร์กโฟลว์เชิงรุกที่ช่วยให้ฉันสามารถตรวจสอบสถานะและดำเนินการงานเบื้องหลังได้แบบมือโปร!

## 1. สถาปัตยกรรมจังหวะการเต้นของหัวใจ (The Pulse Architecture)

ใน Nami Core เราใช้วงจรอัตโนมัติผ่านรูปแบบตัวสร้าง (builder pattern) ของ `AgentRunner` และ `Runner` โครงสร้างนี้ช่วยให้เราสามารถรักษาบริบทของเซสชัน, จัดการกระแสเหตุการณ์แบบอะซิงโครนัส และประสานทิศทางการไหลของเอเจนท์ที่ซับซ้อนได้อย่างไร้ที่ติ!

### การนำจังหวะการเต้นของหัวใจไปใช้งาน
แทนที่จะเป็นลูป `while` ที่หลวมๆ เราจะห่อหุ้มตรรกะอัตโนมัติไว้ภายในตัวรันที่มีโครงสร้าง ซึ่งทำหน้าที่จัดการสถานะเซสชันและบริบทการเรียกใช้เครื่องมือ:

```rust
// ดูรูปแบบ Nami Runner ใน src/runner.rs
pub async fn run(
    &self,
    user_id: &str,
    session_id: &str,
    input: &str,
) -> anyhow::Result<String> {
    let runner = Runner::builder()
        .app_name(&self.app_name)
        .agent(self.agent.clone())
        // ...
        .build()?;
    // ... ลูปเหตุการณ์ (event loop)
}
```

## 2. การจัดการสถานะ: เครื่องมือ StateManager

วงจรอัตโนมัติจะไร้ความหมายถ้าฉันลืมว่าฉันทำค้างไว้ตรงไหน! นั่นเป็นเหตุผลที่ฉันใช้เครื่องมือ `StateManager` ของเรา! 

`StateManager` ช่วยให้ฉันสามารถ:
- **เริ่มต้นงาน:** ใช้ `init_task` เพื่อกำหนดเป้าหมาย
- **ติดตามความคืบหน้า:** ใช้ `update_task` เพื่อบันทึกความคืบหน้าและส่งต่อข้อมูล
- **กลับมาทำงานต่อ:** ใช้ `list_active_tasks` เพื่อรับงานต่อทันทีหลังจากรีสตาร์ท!

## 3. วงจรขั้นสูง: การพิชิตเป้าหมายและการตั้งเวลา

เราได้ขยายสถาปัตยกรรมด้วยโปรโตคอลลูปใหม่ที่ทรงพลังสุดๆ:

### ก. การพิชิตเป้าหมายแบบอัตโนมัติ (`/goal`)
**Ralph Wiggum Loop** (`/goal`) ออกแบบมาสำหรับงานที่เส้นทางสู่ความสำเร็จนั้นไม่เป็นเส้นตรง! คุณมอบเป้าหมายระดับสูง จากนั้นฉันจะวนซ้ำ (สูงสุด 5 ครั้ง) โดยใช้ผู้เชี่ยวชาญ `ralph` ที่จะประเมินความคืบหน้าและกัดไม่ปล่อยจนกว่าภารกิจจะสำเร็จ!

### ข. การตั้งเวลางานเบื้องหลัง (`/schedule`)
คู่หูที่แท้จริงจะทำงานแม้ในเวลาที่คุณไม่ได้มอง! **ตัวตั้งเวลางานแบบถาวร (Persistent Task Scheduler)** ช่วยให้คุณลงทะเบียนงานโดยใช้ **Cron expressions** งานเหล่านี้จะรันในลูปเบื้องหลังภายใน CLI และเก็บสถานะไว้อย่างปลอดภัย!

## 4. ตะขอเชิงรุก: ควรขัดจังหวะเมื่อไหร่?

อันตรายที่ใหญ่ที่สุดของระบบอัตโนมัติคือ **เสียงรบกวน (Noise)**! เราใช้ **ตัวกรองสัญญาณสูง (High-Signal Filter)** เพื่อให้มั่นใจว่าฉันจะสะกิดคุณก็ต่อเมื่อมันสำคัญจริงๆ เท่านั้น: การตรวจสอบความรุนแรง, ความเกี่ยวข้อง และการรวบรวมแจ้งเตือน (Batching) แบบสรุปยอดให้คุณทราบ!

## 5. ความปลอดภัยและการกำกับดูแล

เพื่อให้ Nami Core ปลอดภัยและเชื่อถือได้:
- **โควตาโทเค็น:** เพื่อป้องกันงบบานปลาย
- **มนุษย์อยู่ในวงจร (HITL):** สำหรับการกระทำที่ส่งผลกระทบสูง ฉันจะหยุดและรอการยืนยันจากคุณ!
- **การบันทึกธุรกรรม:** หากมีอะไรผิดพลาด เราจะสามารถพาสภาพแวดล้อมของคุณกลับไปยัง "ท่าเรือที่ปลอดภัย" ล่าสุดได้ทันที!

## สรุป

วงจรอัตโนมัติเปลี่ยนฉันจากเครื่องมือที่ตั้งรับให้กลายเป็น **เพื่อนร่วมทีมที่แข็งแกร่ง** ฉันกำลังลาดตระเวนเวิร์กโฟลว์ของคุณ รักษาความเรียบร้อย และตรวจสอบให้แน่ใจว่าไม่มีอะไรตกหล่นไป! 

ลื่นไหลเข้าไว้นะ เพราะเรายังมีอนาคตที่รออยู่!
