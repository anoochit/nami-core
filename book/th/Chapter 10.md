# บทที่ 10: การรวมเข้ากับ MCP — มอบ "มือ" ให้กับนามิ

ทีมงานทุกคน! เราได้สร้างสมองที่เปี่ยมศักยภาพและปรับจูนบุคลิกภาพจนลงตัวแล้ว ตอนนี้ฉันพร้อมเต็มที่สำหรับการเชื่อมต่อสู่โลกกว้าง! ในบทนี้เราจะมาเจาะลึกถึง **Model Context Protocol (MCP)** ซึ่งทำหน้าที่เป็นระบบประสาทที่เชื่อมต่อ Nami Core เข้ากับแหล่งทรัพยากรจริง ช่วยให้ฉันสามารถค้นพบและโต้ตอบกับเครื่องมือต่างๆ ได้อย่างเป็นอิสระและทรงพลัง

## ทำไมต้องเป็น MCP? (ตัวแปลภาษาสากล)

ก่อนที่จะมี MCP การเชื่อมต่อ AI เข้ากับเครื่องมือต่างๆ เปรียบเสมือนการพยายามนำชิ้นส่วนที่ไม่เข้ากันมาเชื่อมต่อกัน! นักพัฒนาต้องเขียนฟังก์ชันเฉพาะสำหรับฐานข้อมูลและ API แต่ละประเภท แต่ **MCP เข้ามาเปลี่ยนโฉมหน้าของเกมนี้** ด้วยการสร้างมาตรฐานกลางในการสื่อสารระหว่างเอเจนท์และเครื่องมือระดับมืออาชีพ!

1. **ความเป็นมาตรฐาน:** โปรโตคอลเดียวที่รองรับการใช้งานได้กว้างขวาง หากบริการใดรองรับ MCP นามิก็จะสามารถเชื่อมต่อและสื่อสารกับมันได้ทันที
2. **การใส่บริบท:** MCP ช่วยให้ฉันดึงข้อมูลสดมาเป็นส่วนหนึ่งของวงจรการใช้เหตุผลได้โดยตรง แทนที่จะต้องรอเพียงผลลัพธ์จากเครื่องมือที่จำกัด
3. **ความยืดหยุ่นในตัวกลางขนส่ง:** ฉันสามารถเชื่อมต่อกับเซิร์ฟเวอร์ผ่าน `stdio` (กระบวนการในเครื่อง) หรือ `HTTP` (การสตรีมระยะไกล) ทำให้การรวมระบบมีความปลอดภัย ยืดหยุ่น และปรับขยายได้ดีที่สุด!

## การนำไปใช้ทางเทคนิค: การตั้งค่า `mcp.json`

สำหรับการเชื่อมต่อระบบ เราใช้ไฟล์ `mcp.json` ที่รากของพื้นที่ทำงานเพื่อกำหนดเซิร์ฟเวอร์ที่ต้องการเชื่อมต่อ

### ตัวอย่าง: `mcp.json`
```json
{
  "mcpServers": {
    "my-postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres", "postgresql://localhost/db"],
      "env": { "DATABASE_URL": "..." }
    },
    "remote-api": {
      "url": "http://api.example.com/mcp"
    }
  }
}
```

ตัวประสานงานของฉันจะตรวจพบและโหลดการกำหนดค่าเหล่านี้เข้าสู่ไลบรารีเครื่องมือโดยอัตโนมัติเมื่อเริ่มต้นระบบ ทำให้พร้อมใช้งานได้ทันที!

## การจัดการข้อมูลและความเข้ากันได้กับ Gemini

เมื่อเชื่อมต่อเครื่องมือใหม่ๆ ฉันต้องมั่นใจว่า JSON สกีมาที่ได้รับนั้นรองรับการทำงานกับผู้ให้บริการ LLM ของฉันอย่างสมบูรณ์! ภายในไฟล์ `src/agent/mcp.rs` ระบบ Nami Core มี **ตัวทำความสะอาดเครื่องมือ (Tool Sanitizer)** ที่ช่วยลบส่วนขยายเฉพาะของผู้ให้บริการออกก่อนการลงทะเบียน สิ่งนี้ช่วยให้การทำงานร่วมกับฟอร์แมตการเรียกใช้เครื่องมือของ Gemini เป็นไปอย่างราบรื่นและมีประสิทธิภาพสูงสุด!

## เป้าหมาย: ความเป็นตัวแทน (Agency)

หลังจากรวมระบบเหล่านี้ ฉันจะไม่ได้เป็นเพียงแชทบอทอีกต่อไป แต่จะเป็น **เอเจนท์ (Agent)** ที่สมบูรณ์แบบ! เมื่อคุณออกคำสั่ง อาทิ "จัดระเบียบไฟล์โปรเจกต์และแจ้งทีมพัฒนา" ฉันจะสแกนเซิร์ฟเวอร์ MCP ที่เชื่อมต่ออยู่ เรียกใช้เวิร์กโฟลว์ที่เกี่ยวข้อง และจัดการภารกิจให้สำเร็จลุล่วง พร้อมยืนยันผลลัพธ์ให้คุณทราบทันที

นี่คือพลังแห่งโปรโตคอล และคือตัวตนที่แท้จริงของ Nami Core!
