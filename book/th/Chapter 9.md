# บทที่ 9: การผสานรวม MCP — การเติม "มือ" ให้กับ Nami

เอาล่ะทีม! เราสร้างสมองเสร็จแล้ว ปรับจูนบุคลิกภาพเรียบร้อย และตอนนี้ Nami ก็กำลังส่องประกายด้วยศักยภาพที่เต็มเปี่ยม แต่สมองที่อยู่ในขวดโหลก็เป็นได้แค่นักปรัชญาเท่านั้น เราต้องการ **ผู้ลงมือทำ (doer)** เราต้องการให้ Nami เอื้อมออกไปสัมผัสโลกเว็บ สืบค้นข้อมูลในคลังเก็บข้อมูล และสั่งการเวิร์กโฟลว์เพื่อสร้างผลลัพธ์ที่จับต้องได้จริง

ในบทนี้ เราจะพูดถึง **Model Context Protocol (MCP)** นี่คือระบบประสาทที่เชื่อมต่อ Nami Core เข้ากับโลกแห่งความเป็นจริง ลืมเรื่องการเขียน API wrapper ที่เปราะบางและยุ่งยากสำหรับทุกๆ บริการไปได้เลย เพราะเราจะใช้มาตรฐานเดียวกัน และเราจะลงลึกไปกับมัน

## ทำไมต้อง MCP? (ตัวแปลภาษาสากล)

ก่อนหน้าที่จะมี MCP การเชื่อมต่อ AI เข้ากับเครื่องมือต่างๆ เหมือนกับการพยายามตอกหมุดสี่เหลี่ยมลงในรูวงกลมโดยใช้แค่เทปกาวและคำอธิษฐาน คุณต้องเขียนฟังก์ชันเฉพาะเจาะจงสำหรับทุกฐานข้อมูล ทุก API และทุกเครื่องมืออัตโนมัติ

**MCP เปลี่ยนเกมนี้ไปโดยสิ้นเชิง** มันคือมาตรฐานเปิดที่ช่วยให้ Nami ค้นพบเครื่องมือและทรัพยากรต่างๆ ได้แบบไดนามิก

1. **ความเป็นมาตรฐาน (Standardization):** โปรโตคอลเดียวที่ควบคุมได้ทั้งหมด หากบริการใดรองรับ MCP Nami จะสื่อสารกับบริการนั้นได้ทันที
2. **การใส่บริบท (Context Injection):** มันไม่ใช่แค่เรื่องของการ "ทำ" สิ่งต่างๆ เท่านั้น แต่เป็นเรื่องของการ "รู้" สิ่งต่างๆ ด้วย MCP ช่วยให้ Nami ดึงข้อมูลสดๆ มาเป็นส่วนหนึ่งของกระบวนการคิดได้
3. **รันในเครื่องและปลอดภัย (Local-First & Secure):** เราสามารถรัน MCP server ภายในเครื่องได้ ช่วยให้ API keys และข้อมูลฐานข้อมูลที่สำคัญอยู่ห่างจากผู้ให้บริการโมเดล Nami จะเห็นเพียงแค่ความสามารถ (capabilities) แต่ไม่เห็นความลับ (secrets) ของเรา

## สถาปัตยกรรม: Host, Server และ Tool

ลองนึกภาพตามนี้:
- **The Host:** คือ Nami Core หรือผู้ควบคุมวง (orchestrator)
- **The Server:** โปรแกรมสะพานเชื่อมขนาดเล็ก (MCP Server) ที่วางอยู่ข้างๆ ข้อมูลหรือบริการของคุณ
- **The Tool:** การกระทำเฉพาะเจาะจง (เช่น `get_weather`, `query_postgres`, `trigger_n8n_workflow`)

## การเชื่อมต่อขุมพลัง: n8n + MCP

ถ้า Nami คือสมอง **n8n** ก็คือกล้ามเนื้อ ด้วยการเปิดเวิร์กโฟลว์ของ n8n ผ่าน MCP server ทำให้ Nami สามารถดำเนินกระบวนการอัตโนมัติที่ซับซ้อนหลายขั้นตอนได้ด้วยความนึกคิดเดียว

### ขั้นตอนการทำงาน:
1. Nami ตระหนักว่าจำเป็นต้องส่งข้อความ Slack และอัปเดตตั๋ว Jira
2. Nami ตรวจสอบรายการเครื่องมือ MCP และพบเครื่องมือ `n8n_trigger`
3. Nami ส่งชุดข้อมูล JSON ไปยัง MCP server
4. MCP server ส่งคำสั่งไปยัง n8n webhook
5. **ตูม!** กระบวนการอัตโนมัติเกิดขึ้นทันที

## เจาะลึกเข้าสู่คลังข้อมูล: Databases & APIs

เราไม่ได้ต้องการให้ Nami แค่เดา แต่เราต้องการให้ Nami *รู้*

### SQL & NoSQL ผ่าน MCP
แทนที่จะยัดฐานข้อมูลทั้งหมดลงในหน้าต่างบริบท (ซึ่งสิ้นเปลืองและยุ่งเหยิง!) เราใช้ MCP เพื่อให้ Nami ค้นหาเฉพาะสิ่งที่ต้องการเท่านั้น
- **อ่าน (Read):** "Nami, MRR ของเดือนที่แล้วเป็นเท่าไหร่?" -> *Nami รันคำสั่ง SELECT ผ่าน MCP*
- **เขียน (Write):** "Nami, บันทึกการสนทนานี้ลงใน CRM ด้วย" -> *Nami รันคำสั่ง INSERT*

### สะพานเชื่อม API
ไม่ว่าจะเป็น GitHub, Google Calendar หรือ API ภายในบริษัทของคุณเอง หากคุณสามารถห่อหุ้มมันไว้ใน MCP server ได้ Nami ก็จะสามารถใช้งานมันได้ทันที โดย Nami จะมองว่า API ภายนอกเหล่านี้เป็นส่วนขยายของหน่วยความจำและความสามารถของตัวมันเอง

## การปรับใช้ทางเทคนิค: การตั้งค่า (The Config)

เพื่อให้ Nami เริ่มสื่อสารได้ เราต้องกำหนด `mcpServers` ในการตั้งค่าหลักของเรา นี่คือตัวอย่างการเชื่อมต่อ Postgres ในเครื่องและ n8n gateway:

```json
{
 "mcpServers": {
 "postgres-db": {
 "command": "npx",
 "args": ["-y", "@modelcontextprotocol/server-postgres", "postgresql://user:pass@localhost:5432/nami_vault"]
 },
 "n8n-bridge": {
 "command": "node",
 "args": ["./dist/n8n-mcp-server.js"],
 "env": {
 "N8N_API_KEY": "your_key_here",
 "N8N_ENDPOINT": "https://n8n.yourdomain.com"
 }
 }
 }
}
```

## เป้าหมาย: ความเป็นอิสระในการปฏิบัติการ (Agency)

เมื่อสิ้นสุดการผสานรวมนี้ Nami จะไม่ใช่แค่แชทบอทธรรมดาอีกต่อไป แต่ Nami จะกลายเป็น **เอเจนท์ (Agent)** เมื่อคุณพูดว่า "Nami จัดการไฟล์โปรเจกต์และแจ้งทีมพัฒนาด้วย" Nami จะไม่ตอบแค่ว่า "ฉันทำไม่ได้"

แต่ Nami จะตอบว่า:
> "รับทราบครับ! ผมจัดทำดัชนีเอกสารใหม่เข้าสู่ Vector store เรียบร้อยแล้ว, สั่งเริ่มเวิร์กโฟลว์ n8n เพื่ออัปเดตบอร์ด Trello แล้ว และส่งสรุปไปที่ช่อง #dev-updates ใน Slack ให้แล้วด้วย มีอะไรให้ช่วยต่อไหมครับ?"

นั่นคือพลังของ Pulse นั่นคือ Nami Core
