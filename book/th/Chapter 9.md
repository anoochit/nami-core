# บทที่ 9: การสร้างทักษะ (Building Skills)

สวัสดีเหล่านักพัฒนา! พร้อมที่จะอัปเกรดศักยภาพของฉันให้ก้าวล้ำไปอีกขั้นหรือยัง?

แม้ว่าตรรกะหลักของ Nami Core จะมีความแข็งแกร่งเป็นทุนเดิม แต่พลังที่แท้จริงที่ทำให้ฉันมีความสามารถไร้ขีดจำกัดนั้นมาจาก **ทักษะ (Skills)**! ให้ลองจินตนาการว่าทักษะเปรียบเสมือนโมดูลเฉพาะทาง—คือเครื่องมือใหม่ๆ ในเข็มขัดสารพัดประโยชน์ที่ช่วยให้ฉันโต้ตอบกับโลกจริงได้อย่างมีประสิทธิภาพ ในสถาปัตยกรรมปัจจุบัน เราได้ยกระดับจากการใช้ไฟล์ manifest ภายนอก ไปสู่แนวทางที่มั่นคงและปลอดภัยทางประเภทข้อมูล (type-safe) โดยใช้ประโยชน์จากโปรซีเจอรัลมาโคร (procedural macros) ของ Rust มาเริ่มเจาะลึกกันเลย!

## 1. พิมพ์เขียว: การกำหนดเครื่องมือที่ปลอดภัยทางประเภทข้อมูล

หมดยุคของการสร้างไฟล์ `manifest.json` ด้วยตัวเองแล้ว! ปัจจุบันเราสามารถกำหนดเครื่องมือได้โดยตรงผ่านโค้ด Rust โดยใช้มาโคร `#[tool]` แนวทางนี้ไม่เพียงแค่ช่วยให้โค้ดดูสะอาดตา แต่ยังช่วยยืนยันความถูกต้องของอินเทอร์เฟซเครื่องมือ (พารามิเตอร์ต่างๆ) ให้สอดคล้องกับการใช้งานจริงอยู่เสมอ

นอกจากนี้ เรายังใช้เทรต (trait) `schemars::JsonSchema` เพื่อสร้าง JSON สกีมาโดยอัตโนมัติ ช่วยให้ฉันสามารถอ่านและเข้าใจข้อกำหนดของเครื่องมือได้ทันทีในขั้นตอนการคอมไพล์!

### ตัวอย่าง: `tools/weather/mod.rs`
```rust
use adk_rust::serde::Deserialize;
use adk_tool::tool;
use schemars::JsonSchema;
use serde_json::{Value, json};

#[derive(Deserialize, JsonSchema)]
struct WeatherArgs {
    /// ชื่อเมืองที่ต้องการตรวจสอบ
    city: String,
}

/// เรียกดูข้อมูลสภาพอากาศปัจจุบันของเมืองที่ระบุ
#[tool]
async fn get_weather(args: WeatherArgs) -> std::result::Result<Value, AdkError> {
    // ใส่ตรรกะการทำงานที่นี่...
    Ok(json!({ "city": args.city, "temp": 22 }))
}
```

## 2. กลไก: ตรรกะสมัยใหม่

เนื่องจากทักษะในปัจจุบันเป็นฟังก์ชัน Rust แบบเนทีฟ คุณจึงสามารถใช้พลังของภาษา Rust ได้อย่างเต็มที่ โดยไม่จำเป็นต้องพึ่งพาสคริปต์ภายนอกอย่าง Python หรือ Node.js อีกต่อไป!

- **ความปลอดภัยทางประเภทข้อมูล (Type Safety):** โครงสร้างข้อมูลอย่าง `WeatherArgs` ช่วยบังคับให้ข้อมูลมีความถูกต้อง หากฉันพยายามเรียกใช้เครื่องมือด้วยรูปแบบที่ผิดพลาด ระบบจะจัดการและแจ้งเตือนให้ทันที
- **เอกสารประกอบ (Documentation):** คอมเมนต์เหนือฟังก์ชันจะถูกนำไปใช้เป็นคำอธิบายเครื่องมือ ซึ่งช่วยให้ฉันเข้าใจบริบทและช่วงเวลาที่ควรเรียกใช้งานได้อย่างแม่นยำ

## 3. การลงทะเบียน: รูปแบบชุดเครื่องมือ (Toolset Pattern)

การเปิดใช้งานเครื่องมือทำได้ง่ายเพียงเพิ่มฟังก์ชันลงในเวกเตอร์ (vector) ในไฟล์ `mod.rs` ของโมดูลนั้นๆ:

```rust
pub fn weather_tools() -> Vec<Arc<dyn Tool>> {
    vec![Arc::new(GetWeather)]
}
```

เมื่อลงทะเบียนแล้ว ตัวประสานงานของ Nami Core จะตรวจพบเครื่องมือเหล่านี้โดยอัตโนมัติเมื่อเริ่มต้นระบบ ทำให้เครื่องมือพร้อมใช้งานทันที!

## 4. ทำไมแนวทางนี้ถึงเหนือกว่า

- **ประสิทธิภาพสูง:** การรันโค้ดแบบเนทีฟผ่าน Rust มีความรวดเร็วและประหยัดทรัพยากรกว่าการสร้างโปรเซสเชลล์ภายนอกอย่างมหาศาล
- **ความปลอดภัยเชิงโครงสร้าง:** การประมวลผลภายในสภาพแวดล้อมที่จำกัด ช่วยป้องกันช่องโหว่ที่เกิดจากการเรียกใช้สคริปต์ตามอำเภอใจได้ดีกว่า
- **การบำรุงรักษาที่คล่องตัว:** ตรรกะและเอกสารคำจำกัดความอยู่ในตำแหน่งเดียวกัน เมื่อคุณอัปเดตฟังก์ชัน เอกสารและสกีมาทั้งหมดจะอัปเดตตามโดยอัตโนมัติ!

## 5. รายการตรวจสอบสรุปการพัฒนาทักษะ
- [ ] นิยามโครงสร้างอาร์กิวเมนต์ด้วย `Deserialize` และ `JsonSchema`
- [ ] กำกับฟังก์ชัน async ด้วยมาโคร `#[tool]` พร้อมเอกสารประกอบที่ชัดเจน
- [ ] เพิ่มฟังก์ชันลงในเวกเตอร์ชุดเครื่องมือที่เกี่ยวข้องใน `mod.rs`
- [ ] คอมไพล์และทดสอบระบบ เอเจนท์จะค้นพบทักษะใหม่ของคุณโดยอัตโนมัติ!

การสร้างทักษะใหม่คือหนทางสำคัญที่ทำให้ฉันเติบโตจากผู้ช่วยทั่วไปไปสู่ขุมพลังอัจฉริยะที่คู่ควรกับคุณ ฉันตื่นเต้นมากที่จะได้เห็นความสามารถใหม่ๆ ที่คุณจะสร้างสรรค์ขึ้น! **มาสร้างสิ่งที่น่าทึ่งไปด้วยกัน!**
