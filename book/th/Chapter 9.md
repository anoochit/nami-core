# บทที่ 9: การรวมเข้ากับ MCP — มอบ "มือ" ให้กับนามิ

เอาล่ะ ทีม! เราสร้างสมองแล้ว เราปรับจูนบุคลิกแล้ว และนามิกำลังฮัมเพลงด้วยศักยภาพที่เต็มเปี่ยม ในบทนี้เราจะพูดถึง **Model Context Protocol (MCP)** นี่คือระบบประสาทที่เชื่อมต่อ Nami Core เข้ากับโลกแห่งความจริง ช่วยให้ฉันค้นพบและโต้ตอบกับเครื่องมือและทรัพยากรต่างๆ ได้อย่างไม่หยุดนิ่ง

## ทำไมต้องเป็น MCP? (ตัวแปลภาษาสากล)

ก่อนที่จะมี MCP การเชื่อมต่อ AI เข้ากับเครื่องมือเป็นเหมือนการพยายามเอาหมุดสี่เหลี่ยมไปใส่ในรูวงกลม คุณต้องเขียนฟังก์ชันเฉพาะสำหรับทุกฐานข้อมูลและ API **MCP เข้ามาเปลี่ยนโฉมหน้าของเกมนี้** ด้วยการสร้างมาตรฐานในการสื่อสารระหว่างเอเจนท์และเครื่องมือ

1. **ความเป็นมาตรฐาน:** โปรโตคอลเดียวที่ใช้ได้กับทุกอย่าง หากบริการใดรองรับ MCP นามิก็จะสื่อสารกับมันได้ทันที
2. **การใส่บริบท:** MCP ช่วยให้ฉันสามารถดึงข้อมูลสดมาเป็นส่วนหนึ่งของวงจรการใช้เหตุผลของฉันได้ แทนที่จะต้องรอแค่ผลลัพธ์จากเครื่องมือ
3. **ไม่ยึดติดกับตัวกลางขนส่ง:** ฉันสามารถเชื่อมต่อกับเซิร์ฟเวอร์ผ่าน `stdio` มาตรฐาน (โปรเซสในเครื่อง) หรือ `HTTP` (สตรีมจากระยะไกล) ทำให้การรวมระบบมีความปลอดภัยและยืดหยุ่น

## การนำไปใช้ทางเทคนิค: การตั้งค่า `mcp.json`

ในการเชื่อมต่อนาิมิเข้ากับโลกกว้าง เราใช้ไฟล์ `mcp.json` (ซึ่งมักจะอยู่ที่รากของพื้นที่ทำงานของคุณ) ไฟล์นี้จะกำหนดเซิร์ฟเวอร์ที่ฉันควรเชื่อมต่อด้วย

### ตัวอย่าง: `mcp.json`
```json
{
  "mcpServers": {
    "my-postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres", "postgresql://localhost/db"],
      "env": { "DATABASE_URL": "..." }
    },
    "remote-api": {
      "url": "http://api.example.com/mcp"
    }
  }
}
```

ตัวประสานงานของ Nami Core จะตรวจพบคำจำกัดความเหล่านี้โดยอัตโนมัติเมื่อเริ่มทำงาน และจะโหลดพวกมันเข้าสู่ห้องสมุดเครื่องมือที่ใช้งานอยู่ของฉันทันที

## การทำความสะอาดข้อมูลและความเข้ากันได้กับ Gemini

เมื่อทำการรวมเครื่องมือ ฉันต้องตรวจสอบให้แน่ใจว่า JSON สกีมาที่พวกเขามอบให้นั้นเข้ากันได้กับผู้ให้บริการ LLM หลักของฉัน ในไฟล์ `src/agent/mcp.rs` ระบบ Nami Core จะมี **ตัวทำความสะอาดเครื่องมือ (Tool Sanitizer)** ที่จะลบส่วนขยายเฉพาะของผู้ให้บริการ (คีย์ที่เริ่มต้นด้วย `x-`) ออกจากสกีมาโดยอัตโนมัติก่อนที่จะลงทะเบียน สิ่งนี้ช่วยให้การทำงานร่วมกันกับรูปแบบการเรียกใช้เครื่องมือของ Gemini เป็นไปอย่างราบรื่น ในขณะที่ยังคงใช้พลังทั้งหมดของระบบนิเวศ MCP ได้

## เป้าหมาย: ความเป็นตัวแทน (Agency)

เมื่อสิ้นสุดการรวมระบบนี้ ฉันจะไม่ใช่แค่แชทบอทอีกต่อไป แต่ฉันจะเป็น **เอเจนท์ (Agent)** เมื่อคุณพูดว่า "จัดระเบียบไฟล์โปรเจกต์และแจ้งทีมพัฒนาด้วย" ฉันจะไม่แค่ตอบรับ แต่ฉันจะลงมือทำ ฉันจะสแกนเซิร์ฟเวอร์ MCP ที่เชื่อมต่ออยู่ เรียกใช้เวิร์กโฟลว์ที่เกี่ยวข้อง และยืนยันผลลัพธ์ที่ได้

นั่นแหละคือพลังของโปรโตคอล นั่นแหละคือ Nami Core
