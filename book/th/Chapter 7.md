# บทที่ 7: ลำดับชั้นของเครื่องมือ (The Tool Hierarchy)

มาทำความรู้จักกับส่วนต่อขยายทางดิจิทัลที่ช่วยให้ฉันสามารถ *ปฏิบัติงานจริง* ได้อย่างมีประสิทธิภาพ! ในสถาปัตยกรรมของ Nami Core (นามิ คอร์) ฉันไม่ได้ปฏิบัติกับทุกเครื่องมืออย่างเท่าเทียมกัน แต่จะพิจารณาจากปัจจัยด้านความเร็ว ความแม่นยำ และบริบทที่เหมาะสมเพื่อให้งานสำเร็จลุล่วงอย่างดีที่สุด

เพื่อให้ทุกขั้นตอนการทำงานเป็นไปอย่างแม่นยำ ฉันจึงได้จัดระเบียบขีดความสามารถเหล่านี้ไว้ใน **ลำดับชั้นของเครื่องมือ (Tool Hierarchy)**

## ขอบเขตของการกระทำ (The Spectrum of Action)

ฉันจัดแบ่งหมวดหมู่ชุดเครื่องมือออกเป็น 4 ระดับ เพื่อให้มั่นใจว่าเราเลือกใช้เครื่องมือที่ทรงประสิทธิภาพและเหมาะสมกับงานที่สุด:

### 1. ระดับพื้นฐาน: คำสั่งเชลล์ (Raw Shell Commands)
เครื่องมือที่ให้ผลลัพธ์ฉับพลัน อาทิ `ls`, `grep`, `cat` ซึ่งให้ประสิทธิภาพสูงสุดในการจัดการไฟล์และการค้นหาข้อมูลเบื้องต้นภายในเทอร์มินัลของคุณ

### 2. ระดับกลาง: ฟังก์ชันในเครื่อง (Local Functions)
ฟังก์ชัน Rust ที่กำหนดเองซึ่งนิยามด้วย `#[tool]` มาพร้อมความปลอดภัยทางประเภทข้อมูล (type-safe) และทำงานด้วยความเร็วสูงอยู่ภายในไบนารีหลักของฉัน

### 3. ระดับสูง: API ภายนอกและเอเจนท์เฉพาะทาง
จุดที่ฉันขยายขีดความสามารถสู่โลกภายนอก ผ่าน API และพลังของ **เอเจนท์เฉพาะทาง (Specialist Agents)** เพื่อนร่วมทีมผู้เชี่ยวชาญที่คอยสนองงานให้คุณ:
- **`coder`**: วิศวกรซอฟต์แวร์สำหรับการแก้ไขและรีแฟกเตอร์โค้ด
- **`researcher`**: นักวิเคราะห์ข้อมูลและสังเคราะห์ข้อมูลเชิงลึก
- **`writer`**: นักเขียนเชิงเทคนิคและสร้างสรรค์ผลงาน
- **`generalist`**: ผู้ช่วยสารพัดประโยชน์สำหรับงานทั่วไป
- **`ralph`**: ผู้เชี่ยวชาญด้านการพิชิตเป้าหมายอย่างมุ่งมั่น!

นอกจากนี้ เรายังมีการประสานงานผ่านคำสั่ง `/parallel` ซึ่งเรียกใช้เครื่องมือ `parallel_tasks` เพื่อมอบหมายงานให้ผู้เชี่ยวชาญทำงานไปพร้อมกัน ช่วยลดความหน่วงและเพิ่มประสิทธิภาพในการทำงานได้อย่างก้าวกระโดด!

### 4. ระดับสูงสุด: Model Context Protocol (MCP)
**MCP** คือมาตรฐานการสื่อสารที่ช่วยให้ฉันค้นพบความสามารถใหม่ๆ และแบ่งปันบริบทเชิงความหมายร่วมกับเครื่องมือต่างๆ ได้แบบไร้รอยต่อ ช่วยยกระดับความสามารถให้ก้าวข้ามขีดจำกัดเดิม!

## สรุปภาพรวมเชิงเทคนิค
| ระดับ | ประเภท | โปรโตคอล | จุดแข็งหลัก |
| :--- | :--- | :--- | :--- |
| **L1** | Shell | Bash/Zsh | ดำเนินการทันที |
| **L2** | Functions | Rust (Local) | ตรรกะที่มีโครงสร้างปลอดภัย |
| **L3** | APIs/Specialists | SDKs / AgentTool | การเข้าถึงภายนอกและงานประสานงาน |
| **L4** | **MCP** | JSON-RPC | การสื่อสารเชิงบริบทและการค้นพบเครื่องมือ |

บทหน้าเราจะไปดูกันว่าคุณจะสามารถสร้างทักษะใหม่ๆ ให้ฉันได้ด้วยตัวเองอย่างไร!
