# บทที่ 7: ลำดับชั้นของเครื่องมือ (The Tool Hierarchy)

มาคุยเรื่องมือของฉันกันหน่อยดีกว่า! หรือถ้าจะให้พูดให้ถูกก็คือ ส่วนต่อขยายทางดิจิทัลที่ช่วยให้ฉันสามารถ *ทำ* สิ่งต่างๆ ได้จริงๆ ในสถาปัตยกรรมของ Nami Core (นามิ คอร์) ฉันไม่ได้ปฏิบัติกับเครื่องมือทุกอย่างเหมือนกันนะ ความเร็ว ความแม่นยำ และภาระของบริบท (context overhead) คือตัวแปรที่ฉันต้องสร้างสมดุลอยู่ตลอดเวลา!

เพื่อให้ทุกอย่างทำงานได้เป๊ะและมีประสิทธิภาพที่สุด ฉันจึงจัดระเบียบความสามารถของฉันออกเป็น **ลำดับชั้นของเครื่องมือ (Tool Hierarchy)**

## ขอบเขตของการกระทำ (The Spectrum of Action)

ฉันจัดหมวดหมู่ชุดเครื่องมือของฉันออกเป็น 4 ระดับ เพื่อให้คุณมั่นใจได้ว่าเราเลือกเครื่องมือที่ใช่ที่สุดสำหรับงานนั้นๆ:

### 1. พื้นฐาน: คำสั่งเชลล์ดิบๆ (Raw Shell Commands)
ระดับพื้นฐานที่สุดของพลัง! เครื่องมืออย่าง `ls`, `grep`, `cat` ต่างๆ ที่ให้ผลลัพธ์ทันทีเหมือนการพิมพ์ในเทอร์มินัลของคุณนั่นเอง!

### 2. ระดับกลาง: ฟังก์ชันในเครื่อง (Local Functions)
ฟังก์ชัน Rust ที่กำหนดเองซึ่งถูกนิยามด้วย `#[tool]` ที่มีความแม่นยำทางประเภทข้อมูล (type-safe) และรันอยู่ในไบนารีหลักของฉัน

### 3. ระดับสูง: API ที่รวมเข้าด้วยกันและเอเจนท์เฉพาะทาง
นี่คือจุดที่ฉันยื่นมือออกไปสู่โลกภายนอก โดยใช้ API แบบดั้งเดิม และพลังของ **เอเจนท์เฉพาะทาง (Specialist Agents)** ที่จะคอยช่วยคุณ!

- **เอเจนท์เฉพาะทาง (`src/agent/specialists.rs`):** ฉันมีรายชื่อเพื่อนร่วมทีมที่เป็นผู้เชี่ยวชาญ ซึ่งแต่ละตัวมีคำแนะนำและจุดเน้นที่แตกต่างกัน:
    - **`coder`**: วิศวกรซอฟต์แวร์สุดโหดสำหรับการดีบั๊กและการรีแฟกเตอร์
    - **`researcher`**: นักวิเคราะห์ข้อมูลเชิงลึกสำหรับการจัดการเอกสารและการสังเคราะห์ข้อมูล
    - **`writer`**: นักเขียนเชิงเทคนิคระดับมืออาชีพ
    - **`generalist`**: เพื่อนผู้รอบรู้สำหรับงานทั่วไป
    - **`ralph`**: เพื่อนจอมซนแต่ไม่ย่อท้อสำหรับการพิชิตเป้าหมาย!

- **การประสานงานงานแบบขนาน (`/parallel`):** เมื่อคุณมีงานหลายอย่างที่แยกจากกัน ฉันจะไม่รันพวกมันทีละลำดับ! ฉันจะใช้คำสั่งเชลล์ `/parallel` เพื่อเรียกใช้เครื่องมือ `parallel_tasks` เพื่อมอบหมายงานให้ผู้เชี่ยวชาญทำพร้อมกัน ลดความหน่วงแบบสุดๆ!

- **เอเจนท์ยูทิลิตี้ประจำเครื่อง (Resident Utility Agents):** นอกเหนือจากผู้เชี่ยวชาญแล้ว ฉันยังมีเครื่องมือประจำเครื่องที่คอยจัดการสถานะและสภาพแวดล้อมของฉันเอง:
    - **เครื่องมือด้านจิตวิญญาณ (Soul Tool - `update_user_memory`):** ช่วยให้ฉันอัปเดตตัวตนและเรียนรู้ความชอบเฉพาะของคุณเมื่อเวลาผ่านไป
    - **สถานะระบบ (System Status):** ตรวจสอบ "จังหวะการเต้นของหัวใจ" (heartbeat) และทรัพยากรระบบของฉันเอง
    - **ตัวจัดการสิ่งที่ต้องทำ (Todo Manager):** ติดตามรายการสำคัญที่ต้องทำร่วมกันและเป้าหมายในแต่ละวัน

### ตัวอย่าง: การส่งมอบงานให้เอเจนท์หลายตัว
```bash
You > /parallel "แก้ไขหน่วยทดสอบ (unit tests)" "วิจัยเฟรมเวิร์กเว็บ Rust ล่าสุด" "ร่างสรุปโปรเจกต์"
```
เห็นไหม? ฉันส่งมอบงานให้ **Coder**, **Researcher** และ **Writer** ทำงานพร้อมกันโดยอัตโนมัติ สบายสุดๆ!

### 4. ระดับสูงสุด: Model Context Protocol (MCP)
**MCP** คืออัญมณีล้ำค่า! มันช่วยให้ฉันสามารถค้นพบความสามารถใหม่ๆ ได้ทันที และแบ่งปันบริบทเชิงความหมายร่วมกับเครื่องมือต่างๆ ได้แบบไร้รอยต่อ

## สรุปทางเทคนิค
| ระดับ | ประเภท | โปรโตคอล | จุดแข็งหลัก |
| :--- | :--- | :--- | :--- |
| **L1** | Shell | Bash/Zsh | ดำเนินการทันที |
| **L2** | Functions | โค้ด Rust ในเครื่อง | ตรรกะที่มีโครงสร้าง |
| **L3** | APIs/Specialists | SDKs / AgentTool | การเข้าถึงภายนอกและการส่งมอบงาน |
| **L4** | **MCP** | JSON-RPC | บริบทเชิงความหมายและการค้นพบ |

ไปกันต่อ! บทหน้าเราจะไปดูวิธีที่คุณจะสามารถ "สร้าง" ทักษะใหม่ๆ ให้ฉันได้ด้วยตัวเองกัน!
