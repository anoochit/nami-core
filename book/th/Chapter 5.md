# บทที่ 5: หน่วยความจำระยะยาว – คลังวิกิ (The Wiki-Vault)

ทีมงานทุกคน! ระบบของเราทำงานได้อย่างราบรื่นแล้ว แต่ตอนนี้ถึงเวลาที่เราต้องมาทำความเข้าใจเรื่อง **ความคงอยู่ของข้อมูล (persistence)** กันอย่างจริงจัง หากเราไม่สามารถจำสิ่งที่สร้างไว้ได้เมื่อวาน เราก็เปรียบเสมือนการทำงานแบบวนลูปไปวันๆ เท่านั้น!

ใน **Nami Core** (นามิ คอร์) หน่วยความจำไม่ได้เป็นเพียงข้อมูลที่เก็บไว้ในฐานข้อมูล แต่มันคือระบบไฟล์ที่มีชีวิต ซึ่งเราเรียกมันว่า **Wiki-vault (คลังวิกิ)**!

## 1. โฟลเดอร์ `wiki/`: สมองส่วนนอก (Neocortex) ของเรา

ในสถาปัตยกรรมของนามิ โฟลเดอร์ `wiki/` คือรากฐานที่แท้จริงของหน่วยความจำระยะยาว ในขณะที่ `logs/` บันทึก *เหตุการณ์ที่เกิดขึ้น* แต่ `wiki/` ทำหน้าที่บอกเล่าว่าสิ่งต่างๆ *คืออะไร* และ *ทำงานอย่างไร*

ให้นึกเสียว่ามันคือสถานะที่คงอยู่ถาวรของระบบ ไม่ว่าจะเป็น (เอเจนท์) หรือคุณ (มนุษย์) เมื่อเราเรียนรู้สิ่งใหม่ที่สำคัญต่อภารกิจ ไม่ว่าจะเป็นความลับเฉพาะของ API, ขั้นตอนการทำงานที่เหมาะสมที่สุด (deployment workflow) หรือกฎการตั้งชื่อโครงการ มันจะไม่ถูกเก็บไว้เพียงแค่ในประวัติการแชทที่อาจเลือนหายไปตามกาลเวลา **แต่จะถูกยกระดับไปอยู่ในวิกิของเราเพื่อการเข้าถึงที่ยั่งยืน!**

### ทำไมต้องเป็น Obsidian Markdown?
เราเลือกใช้ Markdown ในรูปแบบของ Obsidian เพราะมันช่วยสร้างจุดบรรจบระหว่างสิ่งที่เครื่องจักรสามารถประมวลผลได้กับสัญชาตญาณของมนุษย์:
- **การเชื่อมโยงแบบสองทิศทาง:** ระบบ `[[Linked Notes]]` ช่วยให้เราสร้างเครือข่ายความรู้ที่ทรงพลังและเชื่อมโยงถึงกันได้อย่างไร้รอยต่อ
- **YAML Frontmatter:** ให้ข้อมูลเมตาที่มีโครงสร้างชัดเจน ทำให้ฉันสามารถคัดกรองและค้นหาข้อมูลด้วยโปรแกรมได้อย่างแม่นยำ
- **ความสะดวกในการพกพา:** ข้อมูลทั้งหมดจัดเก็บในรูปแบบไฟล์ที่เรียบง่าย ปราศจากการผูกมัดกับฐานข้อมูลเฉพาะตัว

## 2. โปรโตคอล "วิกิก่อนกูเกิล" (Wiki before Google)

นี่คือกฎทองของ Nami Core: **ตรวจสอบวิกิภายในก่อนที่คุณจะสืบค้นข้อมูลจากเว็บภายนอกเสมอ!**

### เหตุผลสนับสนุน:
1. **บริบทเฉพาะตัว:** เครื่องมือค้นหาทั่วไปอาจให้ข้อมูลกว้างๆ ที่ไม่ใช่แนวทางสำหรับโปรเจกต์ของเรา แต่วิกิคือแหล่งข้อมูลที่ถูกปรับแต่งและจัดเก็บมาเพื่อโครงการของคุณโดยเฉพาะ
2. **ประสิทธิภาพและความชัดเจน:** แหล่งข้อมูลทั่วไปอาจเต็มไปด้วยความไม่แน่นอนและเสียงรบกวน แต่วิกิคือสภาพแวดล้อมที่สะอาดและมีความแม่นยำสูง
3. **ป้องกันการทำงานซ้ำซ้อน:** หากเราแก้ปัญหาได้และบันทึกไว้ในวิกิ เราก็ไม่จำเป็นต้องเสียเวลาค้นหาคำตอบเดิมอีกต่อไป

**ขั้นตอนการปฏิบัติ:**
1. **ตั้งคำถาม:** อาทิ "จะหมุนเวียน (rotate) คีย์ API ได้อย่างไร?"
2. **สแกนข้อมูล:** ตรวจสอบไฟล์ใน `wiki/Operations/Security.md`
3. **ลงมือปฏิบัติ:** ทำตามขั้นตอนที่บันทึกไว้
4. **แผนสำรอง:** กรณีที่วิกิไม่มีข้อมูล ให้สืบค้นจากภายนอก
5. **อัปเดต:** เมื่อพบคำตอบใหม่แล้ว **นำความรู้นั้นกลับบ้าน** เพื่ออัปเดตวิกิทันที!

## 3. การส่งเสริมความรู้ (วงจรการเรียนรู้)

หน่วยความจำระยะยาวจะมีประโยชน์ต่อเรามากที่สุดก็ต่อเมื่อข้อมูลมีความถูกต้องและเป็นปัจจุบัน ใน Nami Core เราใช้กระบวนการ **Knowledge Promotion (การส่งเสริมความรู้)**:

- **ระดับ 1: ชั่วคราว (Chat):** สนทนาแลกเปลี่ยนแนวคิด
- **ระดับ 2: ถูกบันทึก (Logs):** บันทึกการตัดสินใจที่สำคัญในกระบวนการทำงาน
- **ระดับ 3: ถาวร (Wiki):** รูปแบบที่พิสูจน์แล้ว สกีมาสถาปัตยกรรม และเอกสารที่เป็น "แหล่งที่มาของความจริง"

ในขณะที่ฉันทำงานเป็นเอเจนท์ของคุณ ฉันจะคอยสังเกตช่วงเวลาที่เหมาะสมแก่การบันทึกข้อมูล หากเราใช้เวลาแก้ปัญหาซับซ้อน งานสุดท้ายของฉันจะเป็นการร่างไฟล์วิกิสรุปผลไว้ให้คุณอย่างเป็นระบบ!

## 4. การมองเห็นโครงข่ายประสาท (Visualizing the Neural Web)

หน่วยความจำไม่ใช่เรื่องของการจัดเก็บเท่านั้น แต่รวมถึงความเข้าใจในโครงสร้างความสัมพันธ์ เราใช้เครื่องมือ `get_wiki_graph` เพื่อแสดงภาพการเชื่อมต่อระหว่างโน้ตต่างๆ การเชื่อมโยงผ่าน `[[wikilinks]]` ทำให้เราสามารถเห็นแผนผังความรู้ของโปรเจกต์ และระบุได้ว่าโน้ตใดอยู่อย่างโดดเดี่ยว หรือจุดใดที่เป็นแกนหลักสำคัญ (สำคัญต่อการตัดสินใจทางสถาปัตยกรรม)

## 5. การจัดโครงสร้างคลังเพื่อการค้นหา

เพื่อให้หน่วยความจำมีประสิทธิภาพสูงสุด เราแบ่งหมวดหมู่ที่ชัดเจนภายในรากของ `wiki/`:
- `/atlas`: แผนที่เนื้อหา (MOCs) เชื่อมโยงทุกสิ่งเข้าด้วยกัน
- `/specs`: รายละเอียดทางเทคนิคของโปรเจกต์
- `/guides`: คู่มือการปฏิบัติงานแบบทีละขั้นตอน
- `/archive`: ความรู้ที่ล้าสมัย (ย้ายมาเก็บไว้เพื่ออ้างอิง)

ด้วยการจัดเก็บข้อมูลในรูปแบบ Markdown ที่รองรับ YAML ฉันสามารถแปลงไฟล์เหล่านี้เป็นเวกเตอร์และนำมาใช้ในหน้าต่างบริบท (RAG - Retrieval-Augmented Generation) ได้อย่างแม่นยำที่สุด ซึ่งช่วยให้การสืบค้นข้อมูลในอนาคตเป็นการค้นหาในเชิงความหมายที่แท้จริง

ลุยเลย! ความรู้คือพลัง และความรู้ที่ถูกบันทึกไว้คือแรงขับเคลื่อนสู่ความสำเร็จของเรา!
