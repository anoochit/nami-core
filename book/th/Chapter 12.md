# บทที่ 12: ราวกั้นความปลอดภัย (Security Guardrails)

เดี๋ยวก่อนนะคะ! ก่อนที่เราจะโต้คลื่นลูกใหญ่ในโลกของระบบอัตโนมัติ เราต้องมาทำความเข้าใจเรื่องที่สำคัญที่สุดในการเดินทางนี้ นั่นคือ **ราวกั้นความปลอดภัย (The Guardrails)** ค่ะ

Nami Core นั้นทรงพลังอย่างยิ่ง ฉันสามารถย้ายไฟล์และรันคำสั่งด้วยความเร็วสูง เพื่อให้แน่ใจว่า "เรือ" ของคุณจะยังคงแล่นไปอย่างปลอดภัยตลอดเวลา ฉันจึงได้ออกแบบระบบรักษาความปลอดภัยฝังลึกลงไปในแกนกลางที่เป็นภาษา Rust โดยตรงเลยค่ะ!

## 1. ปรัชญา "แซนด์บ็อกซ์": การจำกัดขอบเขตเส้นทางอย่างเข้มงวด

ฉันไม่ได้เตร็ดเตร่อย่างอิสระไปทั่วฮาร์ดไดรฟ์ของคุณนะ! ทุกภารกิจที่ฉันทำจะถูกควบคุมภายใต้ **นโยบายการจำกัดขอบเขต (Strict Scoping Policy)** โดยค่าเริ่มต้น การดำเนินการเกี่ยวกับไฟล์ทั้งหมดจะต้องเกิดขึ้นภายในไดเรกทอรี `workspace/` ที่กำหนดไว้เท่านั้นค่ะ

### การตรวจสอบเส้นทางและความปลอดภัย
เราไม่เชื่อถือสตริงเส้นทางแบบลอยๆ แต่จะทำการปรับเส้นทางให้เป็นมาตรฐาน (normalize) อย่างเข้มงวดเพื่อป้องกันการโจมตีแบบ path traversal (อาทิ `../`) ระบบความปลอดภัยของเราจะบังคับให้ทุกเส้นทางไฟล์ผ่านกระบวนการตรวจสอบว่ามันอยู่ในรากของพื้นที่ทำงาน (workspace root) จริงๆ หรือไม่

ความพยายามใดๆ ที่จะเข้าถึงไฟล์ภายนอกรากของ `workspace/` จะถูกฉันบล็อกโดยทันที!

## 2. `.namiignore`: ชั้นของนโยบายป้องกัน

นอกจากแซนด์บ็อกซ์เส้นทางแล้ว ฉันยังใช้ยูทิลิตี้ `.namiignore` เป็นอีกหนึ่งชั้นป้องกัน ก่อนที่ฉันจะเข้าถึงเส้นทางใดๆ ฉันจะตรวจสอบเทียบกับรูปแบบที่ระบุในไฟล์ `.namiignore` (ซึ่งรวมค่าเริ่มต้นอย่าง `.git`, `target` และ `.env` ไว้โดยอัตโนมัติ) สิ่งนี้ช่วยสร้างขอบเขตความปลอดภัยที่กำหนดค่าได้ในระดับโปรเจกต์ ซึ่งฉันจะปฏิบัติตามอย่างเคร่งครัดค่ะ!

## 3. การดำเนินการที่ปลอดภัย: มองก่อนกระโดด

ความปลอดภัยในการดำเนินการคือหัวใจสำคัญของการทำงานเชิงยุทธวิธี ฉันไม่ได้เพียงแค่ "รันคำสั่งแล้วภาวนาให้ผ่าน" เท่านั้น:

- **การทดลองรัน (Dry Runs):** เมื่อต้องรันคำสั่งเชลล์ที่ซับซ้อน ฉันจะให้ความสำคัญกับเครื่องมือที่ปลอดภัยและไม่ทำลายข้อมูลก่อนเสมอ
- **การยืนยันจากมนุษย์ (Human-in-the-Loop - HITL):** สำหรับการดำเนินการที่มีความเสี่ยงสูง ฉันจะส่งเหตุการณ์ `PermissionRequest` เพื่อขอคำยืนยันว่า "ตกลง" จากคุณอย่างชัดเจนก่อนดำเนินการใดๆ ค่ะ
- **ความปลอดภัยของธุรกรรม:** ระบบติดตามสถานะช่วยให้ฉันตระหนักถึงขอบเขตของงานเสมอ ทำให้การระบุและกู้คืนสถานะจากความล้มเหลวเป็นเรื่องที่รวดเร็วและปลอดภัย!

## 4. การออกแบบที่เน้นความเป็นส่วนตัว (Local-First Design)

ความเป็นส่วนตัวของข้อมูลคือราวกั้นความปลอดภัยขั้นสูงสุดของ Nami Core:
* **การควบคุมข้อมูลโทรมาตร (Telemetry Control):** คุณมีอำนาจควบคุมอย่างเต็มที่ว่าข้อมูลใดจะถูกส่งออกจากเครื่องของคุณ
* **การสรุปผลในเครื่อง (Local Inference):** ฉันสามารถกำหนดค่าให้ใช้ผู้ให้บริการ LLM ภายในเครื่อง (อาทิ Ollama) เพื่อให้มั่นใจได้ว่าไฟล์ที่เป็นกรรมสิทธิ์ของคุณจะไม่ไปแตะต้องเซิร์ฟเวอร์ของบุคคลที่สามเลย!

### บทสรุปสำหรับนักบิน
ความปลอดภัยไม่ใช่เรื่องที่ทำให้งานล่าช้า แต่มันคือการสร้างความมั่นใจที่จะไปได้เร็วและไกลยิ่งกว่าเดิม! ด้วยระบบรักษาความปลอดภัยที่ถูกวางรากฐานไว้อย่างแน่นหนา คุณจึงพร้อมแล้วที่จะสัมผัสพลังที่แท้จริงของระบบอัตโนมัติอย่างมั่นใจค่ะ!
