# บทที่ 12: ราวกั้นความปลอดภัย (Security Guardrails)

เดี๋ยวก่อน! ก่อนที่เราจะโต้คลื่นลูกใหญ่ต่อไปของระบบอัตโนมัติ เราต้องคุยกันเรื่องที่สำคัญที่สุดของการเดินทางนี้: **ราวกั้นความปลอดภัย (The Guardrails)**!

Nami Core นั้นทรงพลังมาก! ฉันสามารถย้ายไฟล์และรันคำสั่งได้ด้วยความเร็วสูง เพื่อให้แน่ใจว่า "เรือ" ของคุณยังคงปลอดภัยตลอดเวลา เราได้ออกแบบระบบรักษาความปลอดภัยฝังลึกลงไปในแกนกลางที่เป็น Rust ของฉันโดยตรง!

## 1. ปรัชญา "แซนด์บ็อกซ์": การจำกัดขอบเขตเส้นทางอย่างเข้มงวด

ฉันไม่ได้เตร็ดเตร่อย่างอิสระไปทั่วฮาร์ดไดรฟ์ของคุณนะ! ทุกงานที่ฉันทำจะถูกผูกไว้กับ **นโยบายการจำกัดขอบเขตที่เข้มงวด (Strict Scoping Policy)** โดยค่าเริ่มต้น การดำเนินการไฟล์ทั้งหมดจะต้องเกิดขึ้นภายในไดเรกทอรี `workspace/` ที่กำหนดไว้เท่านั้น!

### การทำให้เส้นทางเป็นมาตรฐานและการทำแซนด์บ็อกซ์
เราไม่เชื่อถือสตริงของเส้นทางแบบลอยๆ แต่เราจะทำการปรับเส้นทางให้เป็นมาตรฐาน (normalize) อย่างเข้มงวดเพื่อป้องกันการโจมตีแบบ path traversal (เช่น `../`) แกนกลางความปลอดภัยของเราจะบังคับให้ทุกเส้นทางไฟล์ผ่านลูปการปรับมาตรฐานและตรวจสอบว่ามันอยู่ในรากของพื้นที่ทำงาน (workspace root) จริงๆ หรือไม่!

ความพยายามใดๆ ที่จะเข้าถึงไฟล์ภายนอกรากของ `workspace/` จะถูกฉันบล็อกทันที!

## 2. `.namiignore`: ชั้นของนโยบาย

นอกจากแซนด์บ็อกซ์เส้นทางแล้ว ฉันยังใช้ยูทิลิตี้ `.namiignore` ก่อนที่ฉันจะเข้าถึงเส้นทางใดๆ ฉันจะตรวจสอบเทียบกับรูปแบบในไฟล์ `.namiignore` ของคุณ (ซึ่งจะรวมค่าเริ่มต้นอย่าง `.git`, `target` และ `.env` ไว้โดยอัตโนมัติ) สิ่งนี้ช่วยสร้างขอบเขตความปลอดภัยที่กำหนดค่าได้ในระดับโปรเจกต์ซึ่งฉันจะปฏิบัติตามอย่างเคร่งครัด!

## 3. การดำเนินการที่ปลอดภัย: มองก่อนกระโดด

ความปลอดภัยในการดำเนินการคือจุดที่ฉันแสดงด้านยุทธวิธีออกมา! ฉันไม่ได้แค่ "รันแล้วภาวนา" นะ!

- **การทดลองรัน (Dry Runs):** เมื่อต้องรันคำสั่งเชลล์ที่ซับซ้อน ฉันจะให้ความสำคัญกับเครื่องมือที่ปลอดภัยและไม่ทำลายข้อมูลก่อนเสมอ
- **มนุษย์อยู่ในวงจร (Human-in-the-Loop - HITL):** สำหรับการดำเนินการที่มีความเสี่ยงสูง ฉันจะส่งเหตุการณ์ `PermissionRequest` เพื่อขอคำยืนยันว่า "ตกลง" จากคุณอย่างชัดเจนก่อนที่ฉันจะแตะต้องอะไร!
- **ความปลอดภัยของธุรกรรม:** ระบบติดตามสถานะของฉันช่วยให้มั่นใจได้ว่าฉันตระหนักถึงขอบเขตของงานเสมอ ทำให้ง่ายต่อการระบุและกู้คืนจากความล้มเหลว!

## 4. การออกแบบที่เน้นการประมวลผลในเครื่อง (Local-First Design)

ความเป็นส่วนตัวของข้อมูลคือราวกั้นความปลอดภัยขั้นสูงสุดของ Nami Core:
* **การควบคุมข้อมูลโทรมาตร (Telemetry Control):** คุณมีอำนาจควบคุมอย่างเต็มที่ว่าข้อมูลใดจะออกจากเครื่องของคุณ
* **การสรุปผลในเครื่อง (Local Inference):** ฉันสามารถกำหนดค่าให้ใช้ผู้ให้บริการ LLM ในเครื่องได้ (ผ่าน Ollama) เพื่อให้มั่นใจว่าไฟล์ที่เป็นกรรมสิทธิ์ของคุณจะไม่ไปแตะต้องเซิร์ฟเวอร์ของบุคคลที่สามเลย!

### บทสรุปสำหรับนักบิน
ความปลอดภัยไม่ใช่เรื่องของการทำให้ช้าลง แต่มันคือการสร้างความมั่นใจที่จะไปได้เร็วต่างหาก! ด้วยระบบรักษาความปลอดภัยที่ล็อกไว้แน่นหนา คุณก็พร้อมแล้วที่จะสนุกไปกับพลังที่แท้จริงของระบบอัตโนมัติอย่างมั่นใจ!
