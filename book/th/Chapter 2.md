# บทที่ 2: วิศวกรรมแบบ AI-Native (AI-Native Engineering)

ยินดีต้อนรับสู่อีกก้าวสำคัญ! ในโลกที่เทคโนโลยีหมุนไปอย่างรวดเร็ว เราไม่ได้เพียงแค่สร้างแอปพลิเคชันขึ้นมาใหม่ แต่นี่คือการเปลี่ยนผ่านกระบวนทัศน์ครั้งสำคัญของงานวิศวกรรมซอฟต์แวร์

## เป็นมากกว่าแค่ตัวห่อหุ้ม
ในยุคแรกๆ ของการรวม LLM เข้ากับระบบ ซอฟต์แวร์จำนวนมากถูกออกแบบให้เป็นเพียง "ตัวห่อหุ้ม" (wrapper) ที่ทำหน้าที่ส่งต่อพรอมต์ (prompt) เท่านั้น แต่ **วิศวกรรมแบบ AI-Native** คือการเปลี่ยนผ่านที่แท้จริง โดยที่ LLM ไม่ได้เป็นเพียงฟีเจอร์ที่ถูกแปะเพิ่มเข้ามา แต่ทำหน้าที่เป็นหัวใจหลักในการขับเคลื่อนกลไกการใช้เหตุผลของระบบทั้งหมด!

### วงจรการใช้เหตุผล (The Reasoning Loop)
ซอฟต์แวร์แบบดั้งเดิมมักเดินตามตรรกะแบบ if-then-else ที่แข็งทื่อ แต่ระบบ AI-native ของเราทำงานผ่าน **วงจรการใช้เหตุผลที่ยืดหยุ่นและชาญฉลาด** ดังนี้:
1. **การรับรู้ (Perception):** การอ่านเจตจำนงของคุณควบคู่ไปกับบริบทสภาพแวดล้อมจริง (อาทิ วิกิ, ไฟล์ข้อมูล, หรือสถานะระบบ)
2. **การวางแผน (Planning):** การย่อยเป้าหมายที่ซับซ้อนให้กลายเป็นการวางแผนลำดับขั้นตอนและการเรียกใช้เครื่องมือ (tool calls) ที่ทำได้จริง
3. **การดำเนินการ (Execution):** การส่งพลังให้เครื่องมือเฉพาะทาง (เช่น MCP, Shell, หรือการค้นหาบนเว็บ) เพื่อโต้ตอบกับโลกภายนอกได้อย่างแม่นยำ
4. **การสะท้อนคิด (Reflection):** การประเมินผลลัพธ์ที่เกิดขึ้นจริงและปรับเปลี่ยนแผนการอย่างมีชั้นเชิงในแบบเรียลไทม์!

### การออกแบบเพื่อรองรับความไม่แน่นอน
ระบบ AI-native ถูกออกแบบมาโดยยอมรับว่าโลกนี้มีความสุ่ม (non-deterministic) อยู่เสมอ ดังนั้นเราจึงต้องมี:
- **โครงสร้างข้อมูลที่เข้มงวด (Strict Schemas):** ใช้ JSON และสกีมาที่ชัดเจนในการสั่งการเครื่องมือ เพื่อให้แน่ใจว่าการสื่อสารระหว่างระบบมีความแม่นยำ
- **การจัดการบริบท (Context Management):** การคัดกรองและจัดลำดับความสำคัญของข้อมูลแบบอัจฉริยะ เพื่อให้สิ่งที่สำคัญที่สุดอยู่ตรงหน้าต่างบริบทเสมอ
- **ความสามารถในการตรวจสอบ (Verifiability):** การสร้างระบบให้เอเจนท์สามารถย้อนกลับมาตรวจสอบความถูกต้องของงานตัวเองได้โดยอัตโนมัติ

### แนวทางของ Nami
Nami ถูกสร้างขึ้นบนหลักการเหล่านี้ เราใช้ "คลังวิกิ" (Wiki vault) เป็นแหล่งข้อมูลบริบทที่มีชีวิตที่ฉันสามารถสอบถามและอัปเดตได้แบบเรียลไทม์ ซึ่งช่วยก้าวข้ามโครงสร้างข้อมูลแบบเดิมที่หยุดนิ่ง ให้กลายเป็นระบบที่เติบโตไปพร้อมกับคุณ!
