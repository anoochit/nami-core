# บทที่ 6: การดำเนินการตามทักษะ (Skill-Based Execution)

เอาล่ะ ทีม! มาลงลึกถึงกลไกและเครื่องมือกันหน่อย! การคิดน่ะดีแล้ว—อย่าเข้าใจฉันผิดนะ ฉันชอบวงจรตรรกะที่ดีมาก—แต่เอเจนท์สารพัดประโยชน์ที่ไม่สามารถ *ทำ* อะไรได้เลย ก็เป็นได้แค่เครื่องคิดเลขที่ดูหรูหราเท่านั้น!

ใน **Nami Core** (นามิ คอร์) เราเชื่อมช่องว่างระหว่าง "การรู้" และ "การทำ" ผ่านสิ่งที่เรียกว่า **ทักษะ (Skills)**! ถ้า LLM คือสมองของฉัน ทักษะก็คือมือ ตา และเครื่องมือสารพัดประโยชน์ที่ฉันใช้โต้ตอบกับโลกจริง! มาดูกันว่าเราใช้งานมันยังไง!

## 1. "ทักษะ" คืออะไร?

ทักษะคือฟังก์ชันแบบแยกส่วน (modular function) ที่ช่วยให้ฉันโต้ตอบกับสภาพแวดล้อมภายนอก ไม่ว่าจะเป็นการอ่านไฟล์, การส่งสัญญาณหา API หรือการสร้างรูปภาพ ทุกๆ การกระทำจะถูกห่อหุ้มไว้เป็นทักษะที่พร้อมใช้งาน!

ในทางเทคนิค ทักษะคือการจับคู่ระหว่าง **สกีมา + ตรรกะ (Schema + Logic)**:
- **สกีมา (Schema):** คำอธิบายในรูปแบบ JSON (ตามรูปแบบการเรียกใช้เครื่องมือมาตรฐาน) ที่บอกฉันว่าทักษะนั้น *ทำอะไร* และต้องการ *อาร์กิวเมนต์อะไรบ้าง*
- **ตรรกะ (Logic):** โค้ดที่อยู่เบื้องหลัง (ไม่ว่าจะเป็น Python, JavaScript หรือ Bash) ที่ทำหน้าที่รันงานนั้นๆ!

## 2. การรวมกลุ่ม: แนวคิดเรื่อง "ชุดเครื่องมือ" (Toolset)

เราไม่ได้แค่โยนฟังก์ชันดิบๆ เข้าไปมั่วๆ นะ! เพื่อให้หน้าต่างบริบทของฉันสะอาดและการประมวลผลมีประสิทธิภาพ เราจึงใช้ **ชุดเครื่องมือทักษะ (Skill Toolsets)**

การรวมกลุ่มช่วยให้ฉันโหลด "โปรไฟล์" เฉพาะทางขึ้นอยู่กับงานที่ได้รับมอบหมาย! ทำไมต้องพกหัวแร้งบัดกรีไปงานอ่านบทกวีล่ะ จริงไหม?

### รายการชุดเครื่องมือ (The Toolset Manifest)
ทุกชุดเครื่องมือจะมีไฟล์ `manifest.yaml` ที่กำหนดขอบเขตความสามารถของมันไว้อย่างชัดเจน! ด้วยการจัดกลุ่มเหล่านี้ ตัวประสานงานของ **Nami Core** จะสามารถสลับความสามารถที่ใช้งานอยู่ของฉันได้ทันที! ถ้าคุณบอกว่า "ติดตั้งแอปเลย" ฉันจะสลับไปใช้ชุดเครื่องมือ `DevOps` ทันที!

## 3. กลไกการเรียกใช้: จากเจตจำนงสู่การกระทำ

มันไม่ใช่เวทมนตร์ แต่มันคือการประสานงานแบบ 3 ขั้นตอนที่เป๊ะสุดๆ:

### ก. การรับรู้เจตจำนง (Intent Recognition)
เมื่อพรอมต์เข้ามา **Intent Engine** ของฉันจะทำการวิเคราะห์คำขอทันที โดยมองหากริยาและเป้าหมาย!
*อินพุต:* "เฮ้ นามิ หาประวัติล่าสุดแล้วสรุปข้อผิดพลาดให้หน่อย"
*เจตจำนง:* `ACTION: READ_LOGS`, `ACTION: SUMMARIZE`.

### ข. การจับคู่สกีมา (Schema Matching)
ฉันจะมองหาทักษะในชุดเครื่องมือที่ใช้งานอยู่ ซึ่งมีคำอธิบายที่ตรงกับเจตจำนงเป๊ะๆ จากนั้นก็ดึงข้อมูลที่จำเป็นจากพรอมต์ของคุณมาเติมให้ครบ!

### ค. วงจรการดำเนินการ (JIT Execution)
แกนกลางจะรันงานนั้นใน **สภาพแวดล้อมแซนด์บ็อกซ์ (sandboxed environment)** ของเรา เพื่อให้มั่นใจในความปลอดภัยที่สุด! ฉันส่งสัญญาณเรียกใช้ ผลลัพธ์จะถูกส่งกลับมา และฉันจะแปลผลเพื่อแจ้งให้คุณทราบทันที!

## 4. การค้นพบทักษะแบบไดนามิก

นี่คือส่วนที่เจ๋งที่สุด! Nami Core รองรับ **การโหลดทักษะแบบทันเวลา (Just-In-Time - JIT Skill Loading)** หากฉันรู้ตัวว่าไม่มีเครื่องมือที่ต้องการ ฉันสามารถค้นหาจาก `Skill Library` ทั้งในเครื่องหรือจากระยะไกลได้ทันที! สิ่งนี้ทำให้ฉันเบาตัว (lightweight) เพราะฉันไม่จำเป็นต้องเป็นทุกอย่างในเวลาเดียวกัน แต่ฉันสามารถ *กลายเป็น* สิ่งที่คุณต้องการได้ทุกเมื่อ!

## 5. การจัดการข้อผิดพลาดและการแก้ไขด้วยตัวเอง

ทักษะอาจผิดพลาดได้ API อาจล่ม หรือสิทธิ์อาจมีปัญหา แต่สำหรับฉัน มันคือ **วงจรป้อนกลับ (Feedback Loop)** หากทักษะส่งข้อผิดพลาดกลับมา ผลลัพธ์นั้นจะถูกส่งกลับมาหาฉันในฐานะ "การสังเกต" (Observation) ฉันจะวิเคราะห์และลองใช้วิธีใหม่เพื่อแก้ปัญหาโดยอัตโนมัติ!

## สรุป
ทักษะคือสิ่งที่เปลี่ยน LLM ให้กลายเป็นเอเจนท์ตัวจริง ด้วยการจัดระบบชุดเครื่องมือที่แข็งแกร่ง Nami Core จึงยังคงความรวดเร็ว เป็นระเบียบ และทรงพลังอย่างไม่น่าเชื่อ!

**ตอนต่อไปในบทที่ 7:** มาดูเรื่อง **ระบบลำดับชั้นของเครื่องมือ** กัน — วิธีที่ฉันตัดสินใจว่าต้องใช้เครื่องมือระดับไหนถึงจะเหมาะสมที่สุด!
