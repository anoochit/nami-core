# Wiki Tool

## Purpose
A full-featured knowledge management system using Obsidian-style Markdown files. It enables interlinked ideas, research tracking, and automated wiki maintenance.

## Key Entry Points
- `wiki_tools()`: Exports toolset for wiki page management, searching, graphing, and templating.

## Maintenance Note
- Files are stored in the `wiki/` directory in the workspace.
- Supports YAML frontmatter, `[[wikilink]]` syntax, and automated graph building.
