# Imagen Skill

Generates high-quality images using Gemini/Imagen models based on text prompts.

## Best Practices
- **Descriptive Prompts:** Provide detailed descriptions for better results (e.g., style, lighting, composition).
- **Aspect Ratio:** Choose the ratio that best fits your needs ('1:1', '16:9', '9:16').

## Context
- Requires `GOOGLE_API_KEY` set in the environment.
- The script uses the `imagen-3.0-generate-001` model identifier.
